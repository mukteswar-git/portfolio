## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/mukteswar-git/portfolio.git
```

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Open:

```
http://localhost:3000
```

---

## 📦 Production Build

```bash
pnpm build
pnpm start
```
